## Acceptance criteria

1. Demonstrate the outcome above using a concrete fixture and externally visible result.
2. Required failure behavior: A draft or expired-rights song never enters a match manifest.
3. Respect invariant: Client catalogue never includes answer keys or licensed lyric bodies before reveal; withdrawn rights block new scheduling.
4. Use the component ports `ingestSong; validateSong; publishPack; selectEligibleCue` and data scope: songs/private variants; public pack summaries; clue assets; rights records; versioned manifests.
5. No credentials, raw player recordings, unlicensed media, hidden answer keys, or personal data enter logs/public fixtures.
6. Every assigned verification command actually runs and passes; missing tools/tests are blocked, not skipped-success.
7. Commit only owned paths and report evidence, changed files, risks and any unresolved dependencies.
