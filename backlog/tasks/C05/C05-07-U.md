2. Required failure behavior: A nonowner close command returns permission-denied.
3. Respect invariant: At most four members; authenticated membership is required for every room read; invite code is not sufficient for answer access.
4. Use the component ports `createRoom; joinRoom; leaveRoom; closeRoom` and data scope: rooms/{roomId}; roomCodes/{digest}; rooms/{roomId}/members/{uid}.
5. No credentials, raw player recordings, unlicensed media, hidden answer keys, or personal data enter logs/public fixtures.
6. Every assigned verification command actually runs and passes; missing tools/tests are blocked, not skipped-success.
7. Commit only owned paths and report evidence, changed files, risks and any unresolved dependencies.
