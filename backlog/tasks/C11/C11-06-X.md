## Acceptance criteria

1. Demonstrate the outcome above using a concrete fixture and externally visible result.
2. Required failure behavior: Returning from settings rechecks actual permission before enabling capture.
3. Respect invariant: 24kHz mono signed16 little-endian; max20 seconds; stop immediately on grant revocation or background. Never record before consent.
4. Use the component ports `prepareMicrophone; startAttempt; emitFrame; stopAttempt` and data scope: Transient PCM buffer; attempt grant; bounded local retry recording.
5. No credentials, raw player recordings, unlicensed media, hidden answer keys, or personal data enter logs/public fixtures.
6. Every assigned verification command actually runs and passes; missing tools/tests are blocked, not skipped-success.
7. Commit only owned paths and report evidence, changed files, risks and any unresolved dependencies.
